# Финансовый ИИ-Агент

Модульный консольный агент для анализа финансовых отчетов (PDF/TXT) и экспорта метрик и оценки в CSV.

## Структура проекта

```text
financial_agent/
├── main.py                  # Точка входа, настройка UTF-8 и перехват Ctrl+C
├── requirements.txt         # Зависимости Python
├── .env.example             # Шаблон переменных окружения
└── agent/
    ├── __init__.py          # Инициализация пакета
    ├── config.py            # Загрузка настроек, рабочая папка, клиент API
    ├── prompts.py           # Системный промпт агента
    ├── ui.py                # Консольный спиннер с безопасной очисткой строки
    ├── runner.py            # Главный цикл диалога и вызова инструментов
    └── tools/
        ├── __init__.py      # Диспетчер инструментов и экспорт схем
        ├── schemas.py       # JSON-схемы инструментов для LLM
        ├── workspace.py     # Просмотр текущей папки и защита путей
        ├── reader.py        # Чтение PDF и текстовых отчетов
        └── exporter.py      # Сохранение метрик и оценки в CSV
```

## Быстрый старт

1. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

2. Скопируйте `.env.example` в `.env` и укажите свой `OPENROUTER_API_KEY`:

```bash
cp .env.example .env
```

3. Запустите агента из папки, в которой хотите работать с отчетами:

```bash
python main.py
```

## Что улучшено

- **Чистая архитектура**: конфиг, промпты, UI, цикл чата и каждый инструмент разнесены по отдельным модулям.
- **Корректный выход по `Ctrl+C`**: `KeyboardInterrupt` и `EOFError` перехватываются на всех этапах (ввод, ожидание API, чтение PDF, работа спиннера) — агент завершается аккуратно без traceback.
- **Умный выбор папки вывода**: агент использует инструмент `list_workspace_directory`, чтобы увидеть структуру текущей директории, и сам выбирает подходящую подпапку для `save_analysis_to_csv` с защитой от выхода за пределы рабочей директории.
